## 📋 Descripción del Proyecto

Portal web institucional desarrollado para el IES N° 11, diseñado para optimizar la gestión administrativa interna (carreras, publicaciones y control de cuentas de alumnos) mediante una interfaz moderna y segura. Integra herramientas de Inteligencia Artificial (Google Gemini API) para el análisis automatizado de planes de estudio en PDF y un entorno completamente contenedorizado con Docker.

---

## ✨ Características Principales

* **Gestión de Carreras:** Opciones de carga manual y extracción inteligente de datos desde archivos PDF mediante IA.
* **Administración de Alumnos:** Registro seguro de estudiantes con hashing de contraseñas y generación de credenciales.
* **Publicaciones Institucionales:** Módulo para la creación y control de novedades visuales para el portal.
* **Entorno Contenerizado:** Configuración lista para desplegar y ejecutar de forma idéntica mediante Docker.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python, Django
* **Frontend / Estilos:** HTML5, Tailwind CSS
* **Inteligencia Artificial:** Google Gemini API (`gemini-3.8-flash`)
* **Base de Datos y Almacenamiento:** SQLite (Desarrollo) / Supabase (Producción)
* **Contenedorización:** Docker, Docker Compose
